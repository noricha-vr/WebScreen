# 内部 SEO の計画（2026-08-30）

Search Console のエクスポート（過去 3 か月・2026-08-30 取得）から、サイト内で打つ手を優先度付きで整理する。観測の詳細は [2026-08-30-search-console-baseline.md](2026-08-30-search-console-baseline.md)。

## この計画の読み方

**データは PR #98（用途別ページの新設・301 の 1 対 1 化、2026-08-30 デプロイ）より前のもの。** そのため施策を 2 層に分ける。

- **A 層**: PR #98 で受け皿を作り終えており、あとは計測待ち。ここに新しい施策を積まない
- **B 層**: 今回のエクスポートで初めて分かった、まだ手を打っていないもの

## 今回のデータで新しく分かったこと

### 1. 日本語の CTR が米国の半分（最大のレバー）

| 国 | クリック | 表示回数 | CTR | 平均順位 |
|---|---|---|---|---|
| 米国 | 548 | 6,496 | **8.44%** | 7.17 |
| 日本 | 532 | **11,749** | **4.53%** | 7.08 |
| カナダ | 58 | 382 | 15.18% | 6.6 |
| 韓国 | 22 | 202 | 10.89% | 3.93 |

**順位はほぼ同じ（7.08 vs 7.17）なのに CTR が半分**。日本は表示回数が米国の 1.8 倍あるので、伸びしろが最も大きい。順位ではなく**日本語のタイトル・説明文が選ばれていない**ことを示す。

### 2. CTR の勝ちパターンは「変換 / converter」

| クエリ | 表示回数 | CTR | 順位 |
|---|---|---|---|
| `vrchat image converter` | 22 | **45.45%** | 3.14 |
| `vrchat url converter` | 53 | **41.51%** | 1.23 |
| `vrchat screen share` | 33 | 18.18% | 4.52 |
| `vrc 動画url変換` | 131 | 12.98% | 5.98 |
| `vrc 動画プレイヤー 変換` | 84 | 11.9% | 4.11 |

「変換したい」と明示している人には強く刺さる。逆に `vrchat web`（1,274 表示・CTR 0%）のような**漠然としたクエリでは 1 件も取れていない**。文言で「何ができるか」を先に出す根拠になる。

### 3. リッチリザルトはゼロ（ただし打ち手は限定的）

「検索での見え方」のエクスポートが**空** = 構造化データによる特別な表示が一切ない。ただし後述のとおり、FAQ・HowTo は Google 側が廃止済みなので、ここは大きな伸びしろではない。

### 4. デバイスは PC 中心

| デバイス | クリック | 表示回数 | CTR | 順位 |
|---|---|---|---|---|
| PC | 1,218 | 18,673 | 6.52% | 8.08 |

`未確認`: モバイルは順位が良いのに CTR が低いが、デバイス間でクエリ構成が違うだけの可能性がある。タイトル長が原因と決めつけない（判断の根拠には使わない）。

## B 層: 未対応のアクション（優先度順）

### B-1. 日本語のタイトル・説明文を「変換」起点に書き直す ★最優先

**根拠**: 日本の CTR 4.53%（米国 8.44%）・表示 11,749。「変換 / converter」を含むクエリの CTR が 12〜45%。

現在のトップ（`/ja/`）:

```
WebScreen β — Web・画像・PDF を VRChat 用の動画に変換
PDF・画像をアップロードすると、VRChat のビデオプレイヤーで再生できる MP4 の URL を発行します。
```

問題点:
- 先頭がサービス名。日本語 SERP では末尾が切れやすく、**一番刺さる「変換」が後ろに寄っている**
- description が「アップロードすると」から始まり、検索意図（VRChat で見せたい）に届く前に手順の話になっている

改善案（トップ `/ja/`）:

```
VRChat で見せたいものを動画 URL に変換 — Web ページ・画像・PDF | WebScreen
VRChat のビデオプレイヤーに貼るだけで再生できる MP4 の URL を作れます。Web ページ・写真・スライド（PDF）に対応。ワールドを選ばず使えます。
```

同じ方針で `/ja/web/` `/ja/image/` `/ja/pdf/` `/ja/screen-share/` の description も見直す（title は PR #98 で「検索フレーズ先頭」に揃え済みなので、description の書き直しが中心）。

**期待値**: 日本の CTR が 4.53% → 6%（米国並みには届かない前提）で +約 170 クリック/3 か月。

### B-2. `vrchat video player` 系の受け皿を作る

| クエリ | 表示回数 | CTR | 順位 |
|---|---|---|---|
| `vrchat video player` | 51 | 0% | 17.51 |
| `vrchat video player url` | 32 | 0% | 10.22 |
| `vrchat 動画プレイヤー` | 27 | 0% | 10.67 |
| `vrchat video url` | 12 | 0% | 9.42 |
| `vrc 動画プレイヤー 変換` | 84 | 11.9% | 4.11 |

合計 206 表示。**順位 10〜17 位＝コンテンツが無いのに拾われている状態**で、製品との相性は良い（まさに「ビデオプレイヤーで再生できる URL」を作るサービス）。

`/{lang}/video-player/` を新設し、「対応しているワールドの見分け方」「URL の貼り方」「WebScreen で URL を作る手順」を説明する。

**エンコード条件（h264 / baseline / `-g 1` 等）までは書かない**（2026-08-30 判断）。`docs/encode-contract.md` に一次情報はあるが、それを公開すると自分で ffmpeg を回す層を集めることになり、顧客にならない。WebScreen の使い方に絞る。

### B-3. パンくずの構造化データ（BreadcrumbList）

新設した 8 ページはトップの下位階層なので、SERP にパンくずが出るようにする。**FAQPage / HowTo とは違い現役の機能**。

### B-4. Organization / WebApplication の構造化データ

リッチリザルトには直結しないが、Google のエンティティ理解（`webscreen` `web screen` のブランドクエリ 853 表示）に効く。B-3 と同じ実装機会にまとめる。

## 見送る施策と理由

| 施策 | 見送る理由 |
|---|---|
| FAQPage / HowTo 構造化データ | **Google が廃止済み**。HowTo はドキュメントごと削除、FAQPage も 2026-05-07 で検索結果に出なくなった（それ以前も政府・医療系限定）。入れても SERP は変わらない |
| ImagePad 系（`vrchat imagepad 画像` 15 表示 / `vrc イメージ パッド 画像 サイズ` 13） | **製品と検索意図が合わない**。[ImagePad は画像 URL を直接読み込むギミック](https://booth.pm/ja/items/4573315)（VRCImageDownloader 経由、5 秒に 1 回の読み込み制限）で、画像を 1 枚見せるだけなら動画変換は要らない。画像ホスティングの競合サービスも既にある。28 表示と小さいこともあり見送る（2026-08-30 判断）|
| `vrc youtube url変換`（12 表示） | **製品の対象外**。動画入力は #39 で廃止しており、VRChat のプレイヤーは YouTube URL をそのまま再生できる。ページを作ると誇大表示になる |
| `virtual reality screen sharing`（99 表示・順位 25.7）/ `video chat with screen share`（42・46.8）/ `vr screen sharing`（29・19.6） | VRChat 固有ではない一般語で、Zoom 等の競合が強い。順位も 20〜47 位で、投資対効果が悪い |
| モバイル向けの短いタイトル | 上記「4. デバイス」のとおり原因が未確認。順位差ではなくクエリ構成の違いかもしれない |

## 判断が必要な点

**タイトルの「β」を残すか。** 現在は全ページの title 末尾が `— WebScreen β`。

- 残す: 実態に正直（機能は開発途中）。期待値のコントロールになる
- 外す: 「β」は信頼性の判断材料になり、CTR を下げている可能性がある。ただし**未確認**（切り分けるには外して 4 週計測するしかない）

サービスの見せ方の判断なので、実装前に決める。

## 効果の測り方

A 層・B 層とも、**反映から 4〜8 週後**に以下で判定する（新設ページのインデックスに時間がかかるため、直後の数字では判断しない）。

```bash
S=~/.claude/skills/search-console
uv run --project $S python $S/search_console.py \
  --site-url "sc-domain:web-screen.net" --dimensions query --days 90 --limit 500 --sort impressions
```

| 指標 | 現在（2026-08-30） | 目標 |
|---|---|---|
| `https://` の取り分 | クリック全体の 0.6% | 50% 以上（旧 URL からの移行完了） |
| 日本の CTR | 4.53% | 6% 以上 |
| `vrchat web` の CTR | 0%（1,274 表示） | 3% 以上 |
| 画面共有系の CTR | 2.5%（1,831 表示） | 5% 以上 |

国別・デバイス別は API では取りにくいので、Search Console の画面からエクスポートして同じ切り口で比較する。
